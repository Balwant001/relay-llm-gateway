Connecting

One API for every LLM provider

Relay sits between your apps and Claude, OpenAI, and Groq. It caches repeated questions, fails over when a provider goes down, tracks every token and dollar, and lets you compare prompts and models before shipping them.

Caching

Exact and similarity caching means repeated or near-identical prompts cost nothing and return in milliseconds.

Reliability

Automatic failover across providers, a circuit breaker for failing models, and per-key rate limits and budgets.

Visibility

Token and cost tracking per request and per key, Prometheus metrics, and an eval harness for prompt and model comparison.

How to use this demo

  1. Enter the admin key in the sidebar (prefilled on localhost). Open API keys and create a key, or click Get a demo key in the Playground.
  2. In the Playground, send "What is the capital of France?". It is a live call.
  3. Send it again. It returns from the cache with zero cost. Try "What is the capital of Franse?" to see a similarity hit.
  4. Choose the model mock-flaky to watch the gateway fail over to a working model.
  5. Open Overview for cache hit rate, spend, savings, and latency. Open Prompts and evals to compare two models on a test set.

Without provider API keys, the demo uses built-in mock models, so it works fully offline. Add ANTHROPIC_API_KEY, OPENAI_API_KEY, or GROQ_API_KEY on the backend to use real models.

What Relay does

Relay is an LLM gateway: one API in front of several model providers. It adds caching, failover, authentication, rate limits, budgets, cost tracking, metrics, and prompt and model evaluation, which are the things teams build around LLMs once they go to production. Built with FastAPI, PostgreSQL, Redis, Docker, Prometheus, and pytest.
